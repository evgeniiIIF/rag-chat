ОТКЛОНЕНИЯ И ДОЛГИ (осознанные, в коде отражены)
  ⚠️ grade = числовой гейт по score, а не LLM-вызов (research R4 пункт «а»): дешевле и детерминирован,
     смысловой отказ делает схема AnswerDraft (grounded=false). Решение можно пересмотреть отдельным шагом.
  ⚠️ ChatOpenAI получает лимит ответа через extra_body={"max_tokens"}: в langchain-openai 1.8
     typed-поля max_tokens нет (есть max_completion_tokens), а прокси понимает max_tokens.
  ⚠️ graph.add_node вызывается через cast(Any): LangGraph 1.x связывает NodeInputT с TypedDictLikeV2,
     наш GraphState (typing.NotRequired) в этот bound не выводится.
  ⚠️ BM25Retriever тянет DeprecationWarning: langchain-community в статусе sunset — переезд отдельной задачей.
  ⚠️ не покрыто 3 строки: core/config.py:47 (get_settings), core/logging.py:55, infrastructure/index.py:67 —
     порог 80 не задет (факт: 637 stmt / 3 miss).
  ⚠️ память диалога живёт в процессе (InMemorySaver): рестарт бэкенда и второй воркер её теряют.
     Клиент присылает history, поэтому после рестарта контекст восстанавливается из тела запроса —
     но только на один ход. SqliteSaver/PostgresSaver — отдельный шаг.
  ⚠️ condense = дополнительный вызов модели на follow-up (только когда история не пуста).
  ⚠️ eval/run_ragas.py не запускался: нужен поднятый сервис и ключ провайдера.
  ✅ dev-стек проверен запуском (21.11): 56 фрагментов КЦ.docx, оба маршрута графа живые.
  ✅ dev-режим: `docker compose up -d` один раз, дальше uvicorn --reload смотрит на смонтированный
     ./backend/src/v3 (исключены .venv, artifacts, .chroma — иначе записи артефактов вызывали бы рестарт).
     Пересборка нужна только при изменении pyproject.toml/uv.lock (зависимости пекутся в образ).
  ✅ исправлено при запуске в докере: `OpenAIEmbeddings` слал `input` массивами токенов → 400 BAD_REQUEST.
     Теперь check_embedding_ctx_length=False + tiktoken_enabled=False (как в v2): провайдер получает строки.
  ✅ исправлено при запуске в докере: лимит ответа уходит как `max_tokens` через `extra_body`
     (langchain-openai 1.8 знает только max_completion_tokens, прокси понимает max_tokens).
  ✅ исправлено после первой сборки образа: core/config.py падал на `RAGCHAT_DIR.parents[2]`
     (IndexError в плоской раскладке /app). Теперь _ancestor() отдаёт None, data_dir по умолчанию
     в образе — /data (туда compose монтирует backend/data), локально — backend/data.
  ⚠️ prod-путь остался на v2: backend/Dockerfile + docker-compose.prod.yml + nginx/conf.d/prod.conf
     (там /api срезается, а v2 ждёт /chat). Переключение prod — отдельный шаг.
