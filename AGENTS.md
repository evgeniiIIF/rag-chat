# Правила запуска

- НИКОГДА не запускать контейнеры (`docker compose up/build`), скрипты (`*.sh`, `make`, `pytest`, `run_ragas.py` и т.п.) и любые длительные команды — только читать файлы и логи.
- Вместо запуска давать готовую к копированию строку команды, пользователь запускает вручную.
- Это ограничение не отменяет право создавать/править файлы скриптов по просьбе.
